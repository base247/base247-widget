Base247 · Web Chat Widget

任何網站，都能擁有自己的 AI 客服。

這是正式 HTTPS 測試頁。右下角的聊天泡泡會透過 Web Gateway 連接唯一 Shared Core，並依 Widget Key 自動隔離客戶資料。

建議測試順序

  1. 先詢問一般問題，確認 AI 回覆正常。
  2. 重新開一個分頁，輸入「我想找真人客服」。
  3. 確認顯示聯絡資料表單，送出測試 Email。
  4. 重新整理同一分頁，確認對話仍會延續。
  5. 關閉分頁後重新開啟，確認不會看到上一位訪客的對話。

請勿下載後直接雙擊本頁；file:// 沒有可驗證的網站 Origin，必須從 GitHub Pages 開啟。
